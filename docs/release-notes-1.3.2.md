- **修复：联系人条出现重复联系人**：QQ 会把未读数挂在通知标题末尾（`通信12301潘宇锋(2条新消息)`），
  同一个会话因此在条上占好几条 —— 而名字列只有 45dp，几条都截成同一个前缀，看上去就是"重复的联系人"。
  会话名现在会剪掉这类"每来一条消息就变"的后缀，记忆也改按**会话**归档（划掉一个会话就是划掉它，
  不会因为下一条消息换了个标题就复活）。
- **修复：联系人条不能左右滑动**：头像比条宽时整行现在可以横着拖（Flyme 原版就是水平列表），会话少时
  仍然居中；横滑不会误把头像划掉；每个应用记住的会话上限从 12 提到 20（Flyme 的上限）。
- **修复：收藏拖拽排序**（三处；1.3.1 里这功能实际用不了）：
  - **长按只放大、怎么拖都不动** —— 首次组合时把空列表冻进了拖拽状态；
  - **换一次位就自己掉下来** —— 手势原来挂在每一格上，换位后手势被取消（现在挂在收藏区上，按长按落点认格子）；
  - **让位时"在终点闪一下"**、拖拽的图标被让位动画盖住 —— 起始位移改在组合期算，拖拽图层现在画在最上层，
    并补上了让位的滑动动画。
- **修复：扇形双层时半径滑条拖了没反应**：旧几何把「展开扇形半径」当成下限，又和这一圈自己的弦长要求
  取大，于是双层下 180→284dp 整段纹丝不动（反馈原话「开双层根本控制不了半径」）。现在设置就是半径本身，
  外圈**跟着内圈缩放**（不是只在某一段动）。
- **新增：外圈半径可单独控制**：「扇形面板外观」新增开关 + 滑条 —— 双层时可以把外圈从「展开扇形半径」
  里拆出来单独调；滑条不会低于内圈半径（滑到更小会自动回到内圈半径）；单层时这两项置灰。

  - 从 1.3.0 / 1.3.1 升级都无需额外操作；

    （卸载会清理配置与 LSPosed 勾选状态）。
