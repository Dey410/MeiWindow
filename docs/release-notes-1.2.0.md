- **新增：功能页（快捷方式收藏）**。管理页（顶部「更多应用」）现在有「应用 / 功能」两个页签。功能页列出
  系统里能读到的快捷方式：应用自己声明的动态/静态快捷方式（微信扫一扫、支付宝付款码…）、桌面长按固定到桌面
  的捷径，读不到时还有微信/支付宝兜底。点一下加入「已选功能」。
- **已选的功能会出现在扇形（转盘）上**：划出扇形时它们作为 tile 排在收藏应用之后，图标用快捷方式自己的
  （拿不到才是宿主应用图标），点它直接启动，小窗开关跟随设置。「更多」浮层顶部的「已选功能」区也会显示。
  转盘的分页、重按翻页、自动收起都不受影响 —— 功能 tile 与收藏应用一起按「图标数」分页。
- **修复：功能「选了却不出现」的三个各自独立的原因**（都是这次审查挖出来的）：
  1. 面板/转盘要画一条功能，得先在**自己那份**枚举结果里认出这个键；而两个进程的枚举结果并不相同
     （SystemUI 有 LauncherApps 但读不到 App 侧的缓存，App 反过来），认不出来就被静默丢掉。现在 App 会把
     已选功能的名称/宿主/启动 Intent 一起发布到共享组，SystemUI 侧直接用它渲染，不再依赖自己的枚举结果；
     两边都认不出来的键也保留占位项，绝不凭空消失。
  2. `syncLocal`（LSPosed 绑上时把本地真相推给共享组）漏了这两个新键：桥还没绑上时选的功能**永远**进不了
     共享组，而 SystemUI 读的正是共享组 —— 这正是 1.1.11 给「收藏应用」补过的那一课。
  3. 值与戳分两次写入，同一文件上的监听者可能读到「新值 + 旧戳」，于是刚点的那一下被旧值顶掉（表现是
     「第二次开始点了没反应」）。
- **修复：设置页一打开就满速空转**。存盘会通知页面、页面又请求 SystemUI 重扫、重扫再存盘……一圈就是全量枚举
  + 几百张图标的 PNG 编码 + 分片传输，直到页面关掉。现在只在内容真变了时通知，扫描结果有 30s 复用窗口，
  内容指纹相同就不重复上报，App 侧只在缓存空或超过 30 分钟时才请求一次。
- **修复：功能列表的上报会静默失败**。原来按「25 条一批」分片，而 25 个 160px 图标的 Base64 就能超过 Binder
  的 1MB 总缓冲，爆掉又被吞掉 —— App 那边永远收到空列表，看起来就是「功能页是空的」。现在按**字节**切
  （每片 ≤200KB），每片都要回执（且只有从 0 号片连续收到才算收下），每次扫描一个独立会话：App 侧看到的
  是一份完整清单，或者什么都没有。
- **修复：枚举不完整时不再覆盖 App 的缓存**。开机未解锁、LauncherApps 暂时不可用，都会返回一份"少了很多条"
  的清单，而这份上报是**覆盖**语义 —— 照发就等于把用户已经选过的功能删掉，「已选功能」在两处一起变空。
  现在只有「已解锁 + LauncherApps 真的答上来了」才允许上报，其余情况明确记一行 `INCOMPLETE`，诊断页会说明。
- **修复：图标内存与主线程开销**。自适应图标在 3.25 倍密度下会被渲染成 351×351（一条捷径 493KB），一次全量
  扫描几百条就是几百 MB 压在系统界面里；桌面 Provider 的图标 BLOB 同样是桌面尺寸。现在统一收敛到 160px；
  逐像素 `getPixel` 换成整幅 `getPixels`，归一化结果按条目缓存，取应用图标移到 IO 线程并按包名缓存；
  转盘的 tile 只查「已经扫过」的结果（在划出手势中间就地扫描会明显卡顿）。
- **安全收紧**：收藏交接里那条 `startService` 兜底腿删掉了 —— service 的 `onStartCommand` 跑在普通 Handler
  消息里，`Binder.getCallingUid()` 返回的是**自己进程**的 uid，那句校验对谁都成立，任何应用都能用它把两份
  收藏写成空；何况跨应用后台 startService 在 Android 8+ 本来就起不来。给 SystemUI 的收藏广播加了发送方
  校验与 `setPackage`（否则任何注册该 action 的应用都能读到你的收藏列表），快捷方式刷新广播只认模块自己。
  顺带去掉了并不需要的 `QUERY_ALL_PACKAGES`。
- **可核对性**：诊断页新增「功能页（快捷方式）」一项，会区分「枚举不完整」「扫到了但没送到 App」「内容没变
  跳过上报」「面板里的编辑没能发出去」；面板日志里 `MORE_PANEL_TREE … functions=n resolved=m` 两个数不一致
  就说明详情没送到。
- **说明**：功能页是新增能力，不改任何默认值 —— 没选过功能的用户，界面与行为与 1.1.12 完全一致。测试：190 个
  单元测试全绿；设备验收清单见 `docs/test-plan-device.md` 的 A25。
- **装过 1.2.0 测试包（debug 签名）的话，请先卸载再装本包**：本包是发布密钥签名，两者签名不同无法覆盖安装
  （卸载会清掉模块设置、贴边记录与 LSPosed 里的勾选）。
