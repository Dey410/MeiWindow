- **新增：功能页「应用磁贴」**：功能页（面板「更多」与主页收藏管理页）现在会枚举系统里所有可用的
  磁贴服务（`TileService`）—— Wi-Fi、蓝牙、手电筒、勿扰这些系统磁贴，以及各应用自己注册的磁贴 —— 并按
  宿主应用并入快捷方式分组，磁贴排在该应用自己的快捷方式前面。磁贴用和快捷方式一样的圆形图标：圆底填
  应用图标的取色（统一明度），前景是磁贴服务的**真实 icon**（按 0.62 归一化后漂白）；没有自己 icon 的
  磁贴用应用图标兜底，不会再出现「白圆角矩形套在彩色圆里」。更多应用面板里新增「显示磁贴」开关，关掉
  后功能页只显示应用快捷方式；磁贴也可以加入「已选功能」，在扇形/面板里点击直接执行磁贴本身的动作。
  功能页加载期间，网格顶部显示「正在加载功能…」+「第 x 个 / 共 y 个」和一条细进度条。
- **新增：小窗风暴熔断**：竖屏通知开小窗后点某些应用的升级通知（取证的是酷安），目标页会落进一个全新的
  freeform 任务当任务根，应用自己的「回闪屏」重启 + 自带 `MULTIPLE_TASK` 的路由又把它送回来 —— 每轮都
  弹出一个新小窗，31 秒能弹上百个。现在 system_server 和 SystemUI 两个进程各持一份熔断器：2 秒内同一个
  包满 5 次「小窗授予 / 新小窗任务」就判断为风暴，冷却 15 秒（30 秒内再次风暴按 ×4 放大，上限 120 秒），
  冷却期内该应用退化为普通打开 / 不再返回小窗参数；正常手动连开几个小窗不会误判，一个应用风暴时其它
  应用的小窗不受影响。
- **修复：长按菜单的黑色遮罩圆角**：以前遮罩自己画 `18dp × 1/scale` 的圆角，和 ROM 给小窗的真实圆角
  对不上，四角会露出黑边。现在遮罩画成直角矩形，圆角交给窗口 leash 由系统裁剪（实测四角完全重合）。
- **修复：长按菜单用过之后音量键失灵**：菜单是一个全屏 `SurfaceControlViewHost` 窗口，`TYPE_APPLICATION`
  默认可聚焦，菜单关掉后焦点不一定还给下面的小窗，按音量键连系统音量条都不弹。现在菜单窗口加
  `FLAG_NOT_FOCUSABLE`，不再参与键盘焦点（点击/触摸不受影响）。
- **说明**：
  - 从 1.4.0 升级无需额外操作；
  - 若此前安装过 debug 签名测试包，由于发布包使用正式签名，需先卸载旧版本再行安装
    （卸载会清理配置与 LSPosed 勾选状态）。
