- **新增：扇形面板支持「双层」，外圈半径可单独控制**：
  - 内层放「图标数量」个应用 + 一枚「更多」，外层放接着的应用（内层 5 个 → 外层 7 个；「更多」只在内层，外层没有入口）；
  - **「展开扇形半径」现在就是半径本身**（双层时 = 内圈半径），外圈自动落在内圈外面一格；新增
    「外圈半径单独控制」开关 + 滑条，可以只调外圈 —— 滑条不会低于内圈半径（滑到更小会自动回到内圈半径）；
  - 重按翻页后每一页同样是「内层在前、外层在后」，末页多出来的应用仍落在与其它页相同的两条弧上；
  - 默认仍是**单层**（观感与之前完全一致），想少翻几页的用户可在「扇形面板外观 → 扇形层数」切到双层。
- **改进：更多面板的推荐应用**：
  - **推荐显示数量改为手动输入**（4–50 个，默认 12）：弹出数字键盘输入框，填超范围会禁用「确认」并给出提示；
  - 推荐与收藏应用**各自超过 20 个时默认折叠**，第 20 个下面是「展开更多 ▾」，点一下才把剩下的铺开
    （搜索、A–Z 全量列表与已选功能都不折叠）；
  - 扇形**最后一页不满时会用后续推荐补齐**（每页铺满，机器上应用不够时尽力而为）；
    关掉「推荐应用」总开关后，扇形里不再出现推荐应用。
- **改进：轻量打开「选择应用」页**：
  - 顶栏在搜索态整体换成搜索框（返回键先退出搜索、再退出页面），名称 / 拼音 / 首字母 / 包名都能匹配，
    排序规则与更多面板一致；每行的应用图标移到名称与包名之前。
- **修复与稳定性优化**：
  - **双层时半径滑条拖了没反应**：旧几何把「展开扇形半径」当成下限，又和这一圈自己的弦长要求取大，
    于是双层下 180→284dp 整段纹丝不动（反馈原话「开双层根本控制不了半径」）。现在设置就是半径，
    弦长只用来决定**自动**外圈要撑到哪；
  - **联系人条出现重复联系人**：QQ 会把未读数挂在通知标题末尾（`通信12301潘宇锋(2条新消息)`），
    同一个会话因此占好几条。会话名现在会剪掉这类"每来一条消息就变"的后缀，记忆也改按**会话**归档
    （划掉一个会话就是划掉它，不会因为下一条消息换了个标题就复活）；
  - **联系人条不能左右滑动**：头像比条宽时整行现在可以横着拖（Flyme 原版就是水平列表），会话少时
    仍然居中；横滑不会误把头像划掉；
  - **收藏拖拽排序三连修**：长按只放大、怎么拖都不动（首次组合时把空列表冻进了拖拽状态）→
    换一次位就自己掉下来（手势挂在每一格上，换位后手势被取消，现在挂在收藏区上）→
    让位时"在终点闪一下"（起始位移改在组合期算），并补上让位的滑动动画与更顺手的拖拽图层置顶；
  - **顶栏渐进模糊「矮一截」**：模糊带的衰减曲线与着色器结构抄回参考实现（15dp / curve 10 / alpha 0.3），
    删掉叠加的 alpha 遮罩与手写渐变 —— 磨砂现在铺满整条顶栏，栏底不再有一条硬分界；
  - **文本操作误伤**：应用内点链接（如 Gemini 跳转 Google 应用）不再被误判成「文本操作」而进小窗；
    同时兼容 TextClassifier 的文本操作标记；
  - **轻量打开**：未知来源的启动改回放行（不再按通知规则卷进小窗）、「上膛」窗口由 5 秒收回到 2 秒、
    「回到桌面」性质的启动不再小窗、悬浮通知 / 灵动岛与第三方系统插件磁贴入口补齐；
  - **收藏与推荐列表**：同一包名的主应用与分身不再撞列表键。
- **说明**：
  - 「轻量打开」各开关默认保持关闭，需要体验的用户可在设置页中按需开启；
  - 若此前安装过 debug 签名测试包，由于发布包使用正式签名，需先卸载旧版本再行安装
    （卸载会清理配置与 LSPosed 勾选状态）。
