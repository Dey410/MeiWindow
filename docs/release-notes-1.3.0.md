- **新增：实验性功能「轻量打开」（支持六类入口以小窗打开目标应用）**：
  1. **点通知以小窗打开（竖屏/横屏独立开关）**：
     - 支持在通知中心列表点击通知时直接以小窗模式启动目标应用。
     - 支持在接收到实时通知/灵动岛/悬浮横幅时，点击直接以小窗模式启动。
     - 横屏与竖屏点击通知小窗化支持独立控制。
  2. **控制中心长按以小窗打开**：
     - 在控制中心长按任意磁贴（支持原生磁贴及第三方系统插件磁贴），自动以小窗模式打开对应设置/功能页面。
  3. **分享至应用以小窗打开**：
     - 在系统分享弹窗（Chooser）中点击目标应用，自动在小窗中调起分享流程。
  4. **文本操作以小窗打开**：
     - 在选中文本后弹出的系统操作浮层菜单中点击相关应用，以小窗启动。
  5. **应用间跳转以小窗打开**：
     - 支持应用内部发起跨应用跳转时自动进入小窗，提供**白名单模式**（仅名单内应用触发小窗）与**黑名单模式**（除名单外所有跳转触发小窗），支持自定义包名。
- **修复与稳定性优化**：
  - **修复重启 SystemUI 后首次点击/长按失效**：多重 Context 兜底保障机制（视图级 Context、服务缓存及进程级 Application 实例联动），消除 SystemUI 重启初期由于 Context 未就绪与 LSPosed 远程配置同步延迟引起的早期启动退回全屏问题。
  - **延长上膛过渡超时保护**：将过渡 Options 消费超时阈值调整为 5 秒，避免设备刚重启或锁屏过渡动画期间导致小窗启动参数被过早作废。
  - **完善生命周期与热重载**：全面适配 `autoHotReload` 机制，确保模块热更新及跨进程重载后 hook 正确重新建立。
- **说明**：
  - 「轻量打开」各开关默认保持关闭，需要体验的用户可在设置页中按需开启。
  - 若此前安装过 debug 签名测试包，由于发布包使用正式签名，需先卸载旧版本再行安装（卸载会清理配置与 LSPosed 勾选状态）。
