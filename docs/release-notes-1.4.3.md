- **修复：开着「竖屏点击通知以小窗打开」时，系统原有的「下拉通知开小窗」有概率变慢或打不开**：
  通知点击会在进程里留一个 2 秒的「下一次启动换成小窗参数」的上膛状态；如果那次点击的启动没有
  走造 options 的漏斗，残留状态就会被紧接着的「下拉小窗」捡走，把 ROM 自己下拉小窗的动画/任务
  标志盖掉。现在按调用栈识别 ROM 的下拉小窗 / 迷你窗路径（拖拽控制器、`AppMiniWindowManagerImpl`），
  这条路径一律放行、不上膛；同时把上膛改成短命 —— 点击方法返回后 300ms 未被取走就作废
  （2 秒只作为兜底），不再跨到下一次启动。日志新增 `LIGHT_OPEN_SKIP_MINI_WINDOW` /
  `LIGHT_OPEN_OPTIONS_SKIP_MINI_WINDOW`，并新增 `MiniWindowLaunchTest` 4 条单测。
- **说明**：
  - 从 1.4.2 升级无需额外操作；
  - 若此前安装过 debug 签名测试包，由于发布包使用正式签名，需先卸载旧版本再行安装
    （卸载会清理配置与 LSPosed 勾选状态）。
