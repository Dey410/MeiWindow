- **移除：功能页「应用磁贴」及相关取色工具**：磁贴条目、磁贴扫描/点击链路、圆形取色图标和「显示磁贴」开关已全部删除，功能页只保留应用快捷方式与内建聚合支付入口。旧缓存/已选功能里的磁贴记录会自动忽略，不会退化成普通快捷方式。
- **优化：功能页首次加载**：App 进程优先读取 SystemUI 已经上报的快捷方式缓存，避免每次打开都重新枚举 XML 和渲染全部图标；应用图标列表与快捷方式改为并行加载，冷启动明显更快。
- **修复：收藏同步的阻塞与确认语义**：SystemUI 向 App 写收藏/功能时不再在主线程同步 `contentResolver.call`，改为 IO 协程；provider 只在真正写入后返回成功，过期推送会被明确丢弃，避免“显示同步成功但实际没写进去”。
- **修复：推荐/已选缓存过期**：功能页会按当前安装的应用过滤旧的推荐项，卸载应用后不再留下点不开的推荐；同时补充了 rev 边界的同步测试。
- **说明**：
  - 从 1.4.3 升级无需额外操作；
  - 若此前安装过 debug 签名测试包，由于发布包使用正式签名，需先卸载旧版本再行安装
    （卸载会清理配置与 LSPosed 勾选状态）。
