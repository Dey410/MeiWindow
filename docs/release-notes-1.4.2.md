- **改进：边角手势的触发方式重做**：以前在角落按下时要和 MIUI 桌面的 `swipe-up` 监视器抢指针流
  （它按下后 ~8ms 就会 `pilferPointers`，模块必须在 `ACTION_DOWN` 里抢先抢），是一场跨进程竞速 ——
  偶尔抢输就会回桌面，而且按下就抢会让前台 App 丢掉 DOWN（以前「键盘左下角点两下」那类问题就是这么来的）。
  现在改为在 system_server 里直接裁剪桌面 `swipe-up` 监视器的输入表面：左右下角各按「沿底边范围」
  裁掉一列，角落的 DOWN 根本不会送到桌面，竞速从源头消失。模块在 SystemUI 侧变成纯观察者，只有手指
  真的滑过触发阈值时才接管指针流 —— 普通点击、短距离滑动原样留给前台 App。中间底边上滑回桌面、
  左右侧边返回都不受影响；裁剪没生效时自动回退旧的 DOWN 预抢占。
- **修复（本次复查补的隐患）**：
  - 模块被禁用/热重载时把桌面监视器的裁剪还原，不再留下「角落上滑回桌面失效」的残留；
  - 找不到目标监视器时把状态写回「未裁剪」，避免 SystemUI 误以为已裁剪而停止预抢占（竞速会静默回来）；
  - 横屏改用当前方向的真实分辨率计算裁剪（以前 `maximumWindowMetrics` 会拼出 2656×2656 的尺寸）。
- **说明**：
  - 从 1.4.1 升级无需额外操作；
  - 若此前安装过 debug 签名测试包，由于发布包使用正式签名，需先卸载旧版本再行安装
    （卸载会清理配置与 LSPosed 勾选状态）。
