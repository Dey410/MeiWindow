- **新增：迷你小窗长按菜单（静音 / 放大）**：长按迷你小窗约 300ms，从小窗里长出两个按钮 ——
  **静音 / 取消静音**、**放大 / 还原**。「放大」不再由模块自己改窗口尺寸，而是调 ROM 自己的迷你动画入口
  （`MiuiFreeformModeAnimation.startGestureAnimation(11, …)`），所以放大之后**拖动、松手、转屏都不会退回**
  迷你尺寸，再点一次「还原」回到正常迷你大小、仍贴着原来那个角。设置里新增「放大倍率」滑块（110%–200%，
  默认 150%），改完立刻生效，不用重启系统界面。
- **新增：静音按钮在应用没出声时也能用**：以前静音靠 `setPlayerVolume`，必须有"正在播放"的音频通道 ——
  应用暂停时按下去什么都不会发生，看起来就是个死按钮。现在先把"要静音"记成**意图**、图标立刻变，然后等
  应用**真的开始出声**那一刻把音量压到 0；用音量键/音量面板把声音开回来，图标会自己变回去
  （不会退回旧版的"永久已静音"）。点完静音面板自动收起；迷你小窗关掉时恢复音量与 AppOps。
- **修复：联系人条（另一个 ai 的 SurfaceControl 重构）的复查**：条改成挂在显示区下的一块
  `SurfaceControl` + `SurfaceControlViewHost` 之后，复查发现七处"要么崩、要么条再也不出现"的路径，全部修掉 ——
  最要命的两条是「事务失败也标记成已显示 → 条永久不出现」和「surface 失效后 `setPosition` 抛异常 ·
  它跑在主线程的 Choreographer 回调里 = 系统界面崩溃」。另有数据层收紧：搜索/管理下的收藏、标题闸门
  （标题是 `QQ`/`微信`/`TIM` 时必须能从正文取出发送者，取不到就丢弃，绝不把正文当人名）。
- **修复：扇形「更多」面板里 tabrow 到顶后继续上滑，整页会往下沉**：收藏区展开会同时把列表往下推，
  以前只要还有折叠量就展开、不管列表滚到了哪儿；现在只有列表真的回到顶才展开收藏区。
- **修复：横屏居中小窗**：改成**只对竖屏生效**。横屏时迷你小窗点回普通小窗会回到它原来的位置，不再跳到
  屏幕正中（「从哪里来到哪里去」）。
- **新增：手势黑名单**（设置主页 → 「启用手势」下面）：勾上的应用在前台时，角落手势**什么都不做** ——
  看视频、玩游戏时手指贴边不会再误弹出扇形。
- **新增：横屏时需滑动两次**：横屏下第一次上滑只提示一句「再次上滑」，1.6 秒内同一侧再滑一次才打开扇形。
- **改进：不操作自动收起支持 0 秒**：滑块拖到最左 = **松手即收**（以前是"永不收起"）。
- **修复：管理模式下搜索，点搜索结果没法收藏/取消收藏**：搜索结果的格子只有 `+`/`−` 徽标不同，
  而徽标读的那份收藏集合不是可观察状态 —— 点下去值变了、界面不变，看起来就是没反应。两处（面板「更多」
  与主页「收藏应用管理」）共用同一份修好的逻辑。
