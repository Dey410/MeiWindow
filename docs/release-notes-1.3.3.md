- **新增：扇形「双击外部关闭」**：「扇形面板外观」新增开关（默认**关**）。开着时点扇形外面要连点两下才收起
  （第一下只记时间，超过系统双击时限不算），关着仍是一下即收；与「更多面板」的单击/双击收起互不影响。
- **新增：实验性功能「回桌面不收迷你」**：全面屏手势上滑回桌面（以及上滑悬停进最近任务）时，HyperOS 会把
  **所有**小窗一次性收成迷你小窗 —— 这是 ROM 自己的行为（`com.miui.fullscreen_state_change` →
  `allFreeformFromFreeformToMini()` 遍历每一个小窗），不是模块做的。开关打开后模块把这条批量转换拦掉，
  小窗保持原样；模块自己的「小白条上滑 → 迷你小窗」和 ROM 的「从最近任务以小窗打开」都不受影响。
  体检页新增「回桌面不收迷你 hook」一项：装不上会明确写出来（这台 ROM 没有该入口时为提示，不报故障）。
- **修复：收藏应用管理里点应用，结果魅窗自己变成了小窗**：App 进程直接带小窗参数走不通（第三方调用者拿到的
  是空 options），那次小窗请求于是落到调用者自己身上。现在改走与「应用间跳转」完全相同的那条系统链路
  （Intent 带标记 → system_server 的闸门让 ROM 用自己的小窗参数落窗）；安全中心「xx 想要打开 xx」的拦截框
  之后那次启动仍是小窗，拦截框本身也绝不会被带进小窗。
- **修复：收藏那一块不响应上下滑**：顶部收藏区是盖在列表上面的一层可折叠表头，自己不是滚动容器 —— 手指落在
  它上面的拖动没有去处，收藏一多就把可视区盖满、整页滑不动（扇形「更多」面板只有 62% 窗口高度，最早暴露）。
  现在这一层的竖直拖动接回同一条滚动链：先折叠收藏区、剩下的滚列表，惯性照旧；长按拖动排序期间让位给排序。
  同时删掉上滑淡出：收藏区只平移、全程不透明，完全折叠那一刻直接不画，顶栏后面不会透出残影。
